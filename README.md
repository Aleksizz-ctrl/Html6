# Assignment 6. jQuery (Selectors, Effects, Animations)

Student: Borovikov Vyacheslav

## Description
Website with jQuery tasks: selectors, effects, DOM manipulation,
animations and a mini project (accordion menu).

## Pages
- index.html: Task 0-1, setup and selectors
- effects.html: Task 2-4, hide/show, fade, slide
- dom.html: Task 5-7, add/remove elements, attributes, form
- animation.html: Task 8-10, animate()
- project.html: Task 11, accordion menu

## How to run
1. Clone the repository
2. Open index.html in a browser
3. Use the links at the top to switch between pages
4. Open the console (F12) to see the output of Task 0
